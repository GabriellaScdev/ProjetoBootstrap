Olá,seja bem-vindo(a) ao meu portfólio! Aqui você vai encontrar alguns dos meus projetos mais recentes.

Projeto 1: Portifolio Pessoal Responsivo

Desenvolvi um portfólio pessoal moderno e responsivo utilizando HTML5, CSS3 (com Flexbox e Grid) e JavaScript Vanilla. O projeto inclui seções de apresentação, habilidades, projetos e contato, com foco em uma boa experiência do usuário (UX) e carregamento rápido. O layout se adapta a dispositivos móveis e desktops. Também implementei dark mode e transições suaves para melhorar a estética.

Projeto 2:Loja Virtual com React

Criei uma aplicação de e-commerce com React.js, simulando a experiência de uma loja virtual real. A aplicação permite listar produtos, visualizar detalhes, adicionar ao carrinho e simular finalização de compra. Utilizei React Router para navegação e Context API para gerenciamento de estado global do carrinho.

Projeto 3: Aplicativo de Agendas de Tarefas

Desenvolvi uma aplicação de lista de tarefas simples e funcional com JavaScript, HTML e CSS, onde o usuário pode adicionar, editar, marcar como concluída e excluir tarefas. Os dados são armazenados no localStorage do navegador para persistência entre sessões.
